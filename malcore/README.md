# マルこれ（マルウェアコレクション）🦠🛡️ — MVP

**攻めて学ぶセキュリティ**教育ゲーム。マルウェア側を操作して組織システムの
**CIA（機密性・完全性・可用性）** を攻略し、各局面で対応する防御策を学ぶ。
艦これ風の収集・育成・カットインを志向する（企画は `../docs/MALCORE_*.md`）。

> 攻撃手法は **挙動の抽象表現**。動作する実コード・悪用手順は含まない（`../docs/MALCORE_CONCEPT.md` §2）。

## この MVP で遊べること（ステージ1: ゼニス銀行）
- 世代0マルウェア4種の編成で、**3ノード網**（外部→社員PC→[境界FW]→勘定系DB）を攻略。
- **8ターン制限**内に本命「勘定系DB」の CIA 合計を初期の30%以下へ削れば勝利。
  超過＝ブルーチームの封じ込め成功で敗北（滞留時間プレッシャー）。
- **カットイン**（偵察=ハードニング−20 / 診断=脆弱性+25）で本命を「通りやすく」してから撃破。
- **警戒度**が100で足場一斉駆除＝敗北。破壊ルートは速いが警戒度が跳ねる。
- 結果画面で **防御官の総評**（攻撃に対応する現実の対策）を表示。

## あそびかた（王道ルート）
偵察 → 初期侵害(社員PC) → 境界FW回避 → 横展開(本命) → 偵察カットイン → 診断カットイン → 撃破×2（Zeusで機密性を抜く）

## クイックスタート
```bash
node build.mjs        # src を連結して dist/index.html を生成
npm test              # ビルド＋ヘッドレス検証（バランスのリグレッション）
npx serve dist        # ブラウザで開く
node build.mjs --watch
```

## 構成（単一HTML・連結ビルド／むしとりバトルと同じ流儀）
```
malcore/
├─ src/
│  ├─ index.template.html  画面骨組み（/*__CSS__*/ /*__JS__*/ に流し込む）
│  ├─ styles.css           ターミナル/サイバー基調CSS
│  ├─ data/malware.js      世代0マルウェア（C/I/A・ロール）
│  ├─ data/enemies.js      ステージ定義（ゼニス銀行・CIA/H/V・装置・監査）
│  └─ game/core.js         純粋ロジック(MALCORE)＋UI層（document時のみ）
├─ test/sim.mjs            ヘッドレス検証（vmで連結JSを実行し王道/敗北/ゲートを確認）
├─ build.mjs               ORDER順に連結し dist/index.html を生成
└─ dist/index.html         生成物（手編集しない）
```

## 数値の根拠
ダメージ式・ステータス・カットイン増減・制限ターンは `../docs/MALCORE_BALANCE.md` と
`../docs/MALCORE_STAGE_MODEL.md` に準拠。`game/core.js` の純粋ロジックはそのまま実装。

## 開発ルール（むしとりバトル踏襲）
- **`dist/index.html` を手編集しない**（生成物）。編集は `src/`、`node build.mjs` で再生成。
- **ESモジュール化しない**（import/export禁止）。連結順にグローバル共有。
- 文言・コメントは日本語。
- ロジックは DOM 非依存に保ち、`test/sim.mjs` で検証可能にする。
