# マルこれ — 技（わざ）＝攻撃名カットイン ⚡

> 攻撃時に **実在の攻撃手法名** を必殺技として画面に走らせる演出システム。
> 「ディレクトリトラバーサル！！」「クロスサイトリクエストフォージェリ！！！」のように、
> **ITに詳しくない人には“凄そうな呪文”、詳しい人には“必殺技っぽくてかっこいい”** を両取りする。
> ＝ `MALCORE_STATUS_CONTROL.md` のカットインと、A-2の攻撃手法カードを **「技」として統合** する。

- 設計原則: 技名は **実在の手法名（ATT&CK / OWASP）をカタカナ表記**。各技に **対策メモ** を必ずセット（攻撃＝防御学習）。
- 表現方針: 名前と効果の演出のみ。実コード・悪用手順は出さない（`MALCORE_CONCEPT.md` §2）。

---

## 1. 技システムの考え方

- **技 = 攻撃名つきのカットイン**。撃破・横展開・ステータス操作の各アクションが、技名の演出とともに発動する。
- **2系統の技**:
  - 🧬 **固有技（シグネチャ）**: 各マルウェアが最初から持つ代表ムーブ（例: Zeus＝マン・イン・ザ・ブラウザ）。
  - 🃏 **装備技（カード）**: 攻撃手法カードを装備して覚える技（A-2の図鑑がそのまま技になる）。
- **世代が上がるほど派手で強い技**が解放（古典Web攻撃→APT級→ゼロデイ/AI）。コレクション欲を刺激。
- カットイン発動条件・コスト・持続は `MALCORE_BALANCE.md` の枠組みを流用。

### 演出（イメージ）

## 3. ゲームへの組み込み
- **固有技**: マルウェアデータに `waza`（技名・英名・型・ゲージ・叫び・対策）を持たせる。撃破時に技名カットインが走る。
- **装備技**: 攻撃手法カード（A-2）を編成にセット＝その技を使用可能に。マルウェアの得意ゲージと噛み合うと威力UP。
- **既存カットインも技化**: 偵察カットイン＝「ポート・スキャン！」、診断カットイン＝「ヴァルナラビリティ・スキャン！」など名前を与える。
- **演出と学び**: カットイン後・戦闘後に技の **英名＋対策** を表示。「凄そう」→「実はこういう攻撃で、こう防ぐ」と腑に落ちる導線。

### MVPでの最小実装（このコミットで反映）
世代0マルウェア4種に **固有技** を付与し、撃破時に技名カットインを表示：
| マルウェア | 固有技 | ゲージ | 🛡️ 対策 |
|---|---|:--:|---|
| Zeus/Zbot | マン・イン・ザ・ブラウザ！！ | 🔵C | MFA・取引署名 |
| ILOVEYOU | メールワーム・オーバーライト！！ | 🟢I | 添付実行制限・バックアップ |
| MyDoom | ボットネット・コンスクリプション！！ | 🟡A | 外向き接続監視・egress filtering |
| Blaster | バッファ・オーバーフロー！！ | 🟡A/装置破壊 | パッチ・DEP/ASLR・RPC遮断 |

## 4. 命名ガイド（“かっこよさ”の基準）
- **実在手法名を使う**（捏造しない）。カタカナ＋英名併記で「呪文感」と「本物感」を両立。
- 語感が強いものを優先（スローロリス、ゴールデンチケット、ゼロデイ等は特にウケる）。
- レアリティ＝世代＝語の強さ。最上位は「ゼロデイ・エクスプロイト」「AIドリブン・ポリモーフ」等。
- 必ず **対策とセット**。かっこいい技ほど、現実の防御も印象に残る。
