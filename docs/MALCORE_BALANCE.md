## 1. グローバル・ダメージ式（確定版）

```
有効ダメージ = 基礎攻撃力(C/I/A)
             × (1 − 実効緩和率)
             × 命中補正
             × 会心倍率

  実効緩和率  = min(0.80, Σ(噛み合う防御の基礎緩和率) × 防御力倍率)
  防御力倍率  = 0.5 + ハードニングH/100        （H0→0.5 / H50→1.0 / H100→1.5）
  命中補正    = 0.6 + (脆弱性V/100) × 0.8       （V0→0.6 / V50→1.0 / V100→1.4）
  会心倍率    = 確率 (V/100) で ×1.5、それ以外 ×1.0
```
- **緩和は攻撃タイプが噛み合った防御ぶんだけ**乗る（噛み合わなければ素通り＝×1.0）。
- 実効緩和率は **上限0.80**（どんなに硬くても20%は必ず通る）。

## 2. ステータス値域

| ステータス | 範囲 | 備考 |
|---|---|---|
| CIA HP（🔵🟢🟡 各） | 60〜200 | ステージ規模で設定。各ゲージ独立 |
| ハードニング H | 0〜100 | 監査で↑、偵察カットインで↓ |
| 脆弱性 V | 0〜100 | 診断カットインで↑、敵診断で↓ |
| 警戒度 W | 0〜100 | 100で該当層の足場駆除（敗北/後退） |
| 情報/技術/リソース | 0〜∞ | 戦利品。偵察・カットイン・進化の燃料 |

**勝利条件**: 本丸層ノードの CIA を **3ゲージとも0**（または合計を初期比 ≤20% まで）に削る。
**敗北条件**: 主要層の **警戒度 W ≥ 100**（足場一斉駆除でルート寸断）。

## 4. 警戒度モデル

| 行動 | 警戒度 ΔW |
|---|---|
| 静かな回避（フィールド装置をすり抜け） | +2 |
| カットイン発動（偵察・診断） | +5 |
| 撃破（CIAを削る） | +10 |
| フィールド装置の破壊・無効化 | +25 |
| EDRが存在する層での全行動 | ×1.5 |

> 「派手に壊す＝早いが警戒度爆増」「静かに回避＝遅いが安全」のトレードオフを警戒度で表現。

## 9. 戦闘シミュレーション検算（モデルが機能するか）

### 例1: マチ町工業（入門）— ILOVEYOUで完全性を殴る
- I攻撃85、I防御=なし(緩和0)、H20→防御力倍率0.7、V60→命中1.08
- 有効ダメージ＝ 85 × (1−0) × 1.08 ＝ **約92** → I_HP80 を **1ターンで撃破**。
- 結論: 入門は素のスペックで気持ちよく勝てる ✅

### 例2: ゼニス銀行（🔵厚）— Zeusで機密性160を抜く
**(a) カットインなし**
- C攻撃95、プロキシ緩和0.30×防御力倍率(0.5+0.55=1.05)=0.315、命中(V35)=0.88
- 有効＝95 × (1−0.315) × 0.88 ＝ **約57/ターン** → 160に約3T。
- だが4T目にシステム監査でH55→70（防御力倍率1.2、緩和0.36）、診断でV35→20（命中0.76）
  → ダメージ約46に低下＝**もたつくと警戒度MAXに先に到達しやすい** ⚠️

**(b) カットイン活用**（偵察→診断）
- H55→35（防御力倍率0.85、緩和0.255）、V35→60（命中1.08、会心60%）
- 有効(非会心)＝95 × 0.745 × 1.08 ＝ 76、会心込み平均≒ **約99/ターン** → 160を **2Tで撃破** ✅
- 結論: **カットインで“通りやすさ”を作ってから殴る**設計が機能している ✅

### 例3: N省（ラスボス）— 世代0で挑むと？
- AI異常検知でAV緩和0.10と薄いが、EDR等で**全行動の警戒度×1.5**、監査2T毎にH+15・回復20。
- 世代0のC95でも H80(倍率1.3)＋装置で実効緩和が高止まり＋回復で押し返され、**警戒度100が先に来る**。
- 結論: **世代進化（AV緩和を無視できる新種＝AI回避）と短期決戦編成が必須**＝難度と学習が噛み合う ✅

## 10. 調整ツマミ（バランス調整の優先順位）
1. **CIA HP値** … TTK（撃破ターン数）を直接左右。まずここで難度カーブを引く。
2. **制限ターン** … 本命攻略の締切（`MALCORE_STAGE_MODEL.md`）。短いほどカットイン前提の速攻を強制。
3. **監査周期と回復量** … 「もたつき罰」の強さ。短いほど短期決戦を強制。
4. **カットイン増減量(±20/±25)** … 上振れ幅。大きいほど偵察重視ゲーに。
5. **警戒度ΔW** … 派手プレイvs静かプレイの傾き。
6. **基礎緩和率** … 防御タイプ間の相性の鋭さ。

> 目安TTK: 入門1〜2T / 中盤3〜5T / ボス6〜10T（カットイン前提）。これを外れたら上から順に調整。
