# マルこれ — 攻撃モデルの進化（単段 → 多段キルチェーン）⚔️

> フェーズ0-A の設計。**時代が進むと「攻撃の構造」そのものが進化する** ことをゲームの核に据える。
> 2000年代＝マルウェア単体で完結する直接攻撃。2000年代後半〜2010年代＝踏み台・クライアント端末を侵害し、
> バックドア／ボット化で足場を作ってから本丸を攻める **多段攻撃**。これが本作最大の“成長の手触り”になる。

- 関連: `MALCORE_CONCEPT.md`（全体像）／`MALCORE_GEN0_MALWARE.md`（世代0データ）
- 設計原則どおり、各メカニクスに **防御マッピング** をセットで記載。

---

## 1. 時代ごとの攻撃モデル早見表

| 世代 (時代) | 攻撃モデル | 構造 | プレイ感 |
|---|---|---|---|
| **世代0** (2000s) | **単段・直接** | 敵CIAを直接削る | 1体で殴る。素朴で爽快。入門。 |
| **世代1** (2000s後半〜2010s前半) | **2段（踏み台→本丸）** | クライアント侵害→バックドア→本丸 | 足場づくりの概念が登場 |
| **世代2** (2010s後半) | **多段キルチェーン** | 偵察→初期侵害→永続化→権限昇格→横展開→本丸 | 標的型(APT)。編成と段取りの戦略 |
| **世代3〜4** (2020s〜) | **多段＋自動化/AI** | チェーンの自動連鎖・適応型回避 | 半自動で連鎖、敵も適応 |

> ポイント: **世代0は「攻撃力の勝負」**、**世代1以降は「段取り（攻略ルート）の勝負」**へとゲーム性が質的に変わる。

## 2. 世代0 モデル — 単段・直接攻撃（2000年代）

```
[ あなたのマルウェア ] ──直接──▶ [ 敵サーバ：CIAゲージ 🔵🟢🟡 ]
```
- 敵は **単一のシステム**。マルウェアの C/I/A 攻撃力でゲージを直接削る（`MALCORE_GEN0_MALWARE.md` の数値）。
- 警戒度が上がり切ると駆除＝敗北。シンプルな殴り合い。
- **これが成立する史実的理由**: Slammer や Blaster のように、脆弱性を突けば単体で増殖・破壊が完結した時代。

---

## 3. 世代1以降モデル — 多段攻撃（敵が“層構造”になる）

世代1から、敵は単一HPではなく **層構造のネットワーク** になる。本丸（CIAゲージ）には直接届かない。

```
            ┌─────────────────────────────┐
   外部公開層 │  Webサーバ / メールGW    ← 初期侵害の入口        │
            └──────────────┬──────────────┘
                          │ 横展開 (pivot)
            ┌──────────────┴──────────────┐
 クライアント/  │  社員PC / 部門サーバ  ← バックドア設置・ボット化   │
   踏み台層    └──────────────┬──────────────┘
                          │ 権限昇格 + 横展開
            ┌──────────────┴──────────────┐
   内部/本丸層 │  ドメインコントローラ / DB / 基幹               │
            │  ★ CIAゲージ 🔵🟢🟡 はここにある ★             │
            └─────────────────────────────┘
```

### ノードの状態遷移
各ノードは次の状態を持つ。本丸層のノードを **制圧** して初めて CIA を削れる。

```
未接触 ──偵察──▶ 偵察済み ──初期侵害──▶ 侵害(foothold)
                                  │
                          バックドア/ボット化（永続化）
                                  ▼
                              足場確立 ──横展開/権限昇格──▶ 制圧
```

- **足場確立**したノードは **pivot 拠点**になり、隣接する内側の層へ横展開できる。
- 足場は **永続化**＝EDRに駆除されなければ次戦でも一部維持（再侵入が楽になる）。

## 4. 多段モデルの新メカニクス（と防御マッピング）

| メカニクス | 攻撃側のやること | 主な手法系統 | 🛡️ 防御マッピング |
|---|---|---|---|
| **偵察** | 層構造・弱点ノードの可視化（情報レベル消費） | スキャン/OSINT系 | 露出資産管理、異常スキャン検知 |
| **初期侵害** | 外部層 or クライアント端末に侵入 | フィッシング/公開脆弱性 | メール検査、MFA、パッチ、WAF |
| **永続化（足場）** | バックドア設置・ボット化で拠点化 | RAT/ボット系 | EDRふるまい検知、自動起動の監視 |
| **権限昇格** | 層境界を越える権限を奪取 | 権限昇格系 | 最小権限、権限分離、LAPS的運用 |
| **横展開 (pivot)** | 足場から内側ノードへ移動 | 認証情報悪用/横展開系 | ネットワーク分離、ラテラル検知、MFA |
| **本丸制圧** | 内部層でCIAを削る | 窃取/破壊/暗号化系 | ゼロトラスト、バックアップ、DLP |

> **ゼロトラスト＝“侵害前提”の守り**。世代2以降のボス（政府「N省」等）は、足場を取られても本丸到達が難しい設計にして、
> プレイヤーに「分離・最小権限・検知」の価値を体感させる。

## 5. ボットネットを“育つ資産”にする

世代1で登場する **足場の蓄積＝ボットネット** を、艦これの資源/艦隊規模のような成長資産にする。

- 制圧せず**足場のまま残したノード数 = ボットネット規模**。
- ボットネット規模が大きいほど:
  - 🟡**可用性攻撃力（DDoS）が上昇** ← Sobig/MyDoom/Conficker の系統と整合
  - **並列偵察**が速くなる／**再侵入の冗長性**が増す（1拠点を駆除されても復帰しやすい）
- リスク: 規模が大きいほど **警戒度・検知率が上がる**（騒がしいボットネットは見つかる）。静かに保つか、火力に振るかの駆け引き。
- 🛡️ 防御: C2通信のDNS/プロキシ監視、DGA検知、ビーコン検知（=ボットの“息継ぎ”を捕まえる）。

## 6. 編成（艦隊これくしょん的な深み）

多段化により、マルウェアに **役割（ロール）** が生まれる。1体で全部はできない＝**編成**が攻略の鍵になる。

| ロール | 仕事 | 世代0の該当例 |
|---|---|---|
| 🚪 **侵入（Access）** | 外部/クライアントへ初期侵害 | ILOVEYOU、(フィッシング系) |
| 🏴 **足場（Foothold）** | バックドア化・ボット化・永続化 | MyDoom、Sobig、Conficker |
| ↔️ **横展（Pivot）** | 権限昇格・横展開で内側へ | Nimda、Conficker |
| 💥 **撃破（Strike）** | 本丸でCIAを削る | Zeus（🔵）、ILOVEYOU（🟢）、Slammer/Blaster（🟡） |

- 例: 「フィッシングで侵入 → MyDoomで足場/ボット化 → Confickerで横展開 → Zeusで本丸の機密性を抜く」という **攻略ルート**を組む。
- これにより `MALCORE_GEN0_MALWARE.md` の各マルウェアに、後で **ロールタグ**を付与する（次アクション A-2 で対応）。

## 7. 難度カーブと敵の進化との対応

| 敵（架空） | 採用モデル | 層の数 | 守りの主眼 |
|---|---|---|---|
| マチ町工業 | 世代0（単段） | 1 | パッチ・バックアップ |
| ゼニス銀行 | 世代1（2段） | 2 | MFA・監視 |
| 電力公社 | 世代2（多段） | 3（OT分離） | 分離・冗長化 |
| N省 | 世代2+（多段・APT） | 3+ゼロトラスト | ゼロトラスト・脅威ハンティング |

- プレイヤーの世代進化と敵のモデル進化が **歩調を合わせて**上がる。
- 敗北条件は層ごとの **警戒度MAX → 該当層の足場を一斉駆除**（＝攻略ルートの寸断）。
