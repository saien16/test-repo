## 0. 現状の到達点（レビュー共通見解）

MVPは"企画段階"ではなく **強いバーティカルスライス**。エンジン（`gaugeDamage`/`strikeWarn`+`detectMul`/`gaugeMit` の3チョークポイント、隠密・警戒度ループ、世代進化、収集/解放の永続化）はデータ駆動で拡張に耐える設計。ソフトローンチに近い位置にある。

**弱点（共通指摘）**: コンテンツ物量が薄い（今回まで 4ユニット/12カード）、UIが1画面詰め込み（briefingに編成+進化+装備、battleに全行動をフラット表示）でコンテンツ増に伴い破綻する、オンボーディング無し、長期リテンション未検証。

## 1. ポジショニング & ターゲット（商用化戦略レビュー）

- **主対象**: 前提知識ゼロの「セキュリティに興味はあるが敷居を感じている大人・学生」。新卒/若手IT、ブルーチーム志望、研修対象の一般職、KanColle系育成が好きなゲーマー。調査(§1)が示す**未充足のカジュアル層**を狙う。
- **キャッチ**: 「攻めて学ぶ、遊べるセキュリティ図鑑」— 前提知識ゼロで、マルウェアを擬人化して集めて育てながら攻撃と対策がセットで身につく。
- **差別化（すべて調査裏付けあり）**: 攻撃者視点の新規ジャンル★★ / 抽象概念のゲーム化適性★★★ / 読める強敵→習熟の弧★★★ / 攻撃に必ず対策が付く（行動↔学習の結合）★★★。
- **避ける層**: CTF層・専門職（調査上すでに充足・抽象化を批判されやすい）。ただしATT&CK/OWASPタグは信頼性シグナルとして残す。

## 2. ビジネスモデル（教育タイトル＝略奪的ガチャは採らない）

**二層モデルを推奨**:
1. **消費者向け**: 無料Web版（世代0＋序盤ステージ）→ **プレミアム・コンテンツパック**（世代1〜4の"脅威史"パック、ステージ章）。静的HTML＋githackで限界費用ほぼゼロ。
2. **B2B教育ライセンス（高マージンの本命）**: 学校・企業のセキュリティ意識向上研修へブランド/ホスト版＋「教材モード」を販売。非機能・抽象化フレーミングこそがB2B販売を可能にする資産。

現行の `devP`（プレイで稼ぐ通貨）は維持。**課金ガチャは入れない**。ガチャ感が欲しければ devP で"解析"して**確定アンロック**（運でなく意志）。

## 3. コンテンツ・ロードマップ（v1.0の最小商用スコープ）

| 指標 | 現状→v1.0目標 |
|---|---|
| ユニット | 12 → **24〜30**（4世代バケット、2世代分を端から端まで遊べる） |
| カード | 20 → **24〜30**（ATT&CK戦術の穴埋め: 永続化/横展開/C2/持ち出し） |
| ステージ | 7（維持）＋ **チュートリアルステージ** |
| 図鑑 | ユニット図鑑の追加、フィルタ/サムネイルグリッドで50+に耐える |

**フェーズ**: MVP(≒現状) → soft launch v0.5(チュートリアル+図鑑+リテンション計測) → v1.0(2世代分の育成が"体感"できる+パック課金導線+PWA) → v1.x(英語版+B2B教材モード+防御モード)。

## 4. コンプライアンス/倫理（"マルウェア"テーマの必須ガードレール）

1. **ストアポリシー**: Web/PWA先行。ネイティブ化時は"educational/abstracted/non-functional"を前面に。
2. **実攻撃の助長回避**: 抽象挙動のみ・実行不能。**CIゲート化**（`test/sim.mjs` に、実CVE番号/実IP・ホスト名・鍵/コピペ可能なコマンドを含む記述でビルドを落とすlint）。
3. **実組織/実マルウェア名**: 標的は架空（X省リネーム済）。ユニット名は"歴史的アーキタイプ"の注記＋実名に機能する手口を絶対に紐付けない。
4. **教育フレーミングの一貫性**: **全カードに `defense` 必須**（同CIゲートで強制）＝ブランドの盾。
5. `ETHICS.md`（抽象化契約）＋ゲーム内ディスクレーマー画面を用意。

## 5. 実装済み（今イテレーション）

**① コンテンツ増量（ask a）**
- マルウェア 4→**12**（世代0: Nimda/SQL Slammer/Code Red/Sasser/Conficker、世代1: CryptoLocker/Emotet/Mirai を追加）。全ユニットに `archetype`（機密特化/完全DoT/可用DoS/装置破壊/横展開/バフ支援）を付与。
- 攻撃カード 12→**20**（phishing/password_spray/ssrf/c2_beacon/dns_poison/golden_ticket/supplychain/forkbomb）。各カードに `defense` 併記を維持。
- `ROSTER` を `MAL` から自動生成し、新ユニットが編成候補へ自動で並ぶように。

**② UIメニュー化（ask b）**
- **バトル**: 全行動フラット表示 → **カテゴリタブ制のアクションドック**（侵入/横展開/支援/撃破/カード）。各タブに"実行可能な行動数"バッジ。本命到達で撃破タブを自動選択。→ ユニット/カードが増えても画面は常に1カテゴリ分。
- **ブリーフィング**: 編成+装備の詰め込み → **編成/装備のサブタブ**に分割。
- **モバイル堅牢化**: `.path` を横スクロール化（多段でも1行維持）、タブは横スクロール＋`touch-action:manipulation`。

これらは UIレビューが指摘した「3つの継ぎ目をメニューに変える」うち2つ（フラットな行動グリッド→カテゴリタブ、詰め込みbriefing→サブタブ）に対応。

## 6. 今後のロードマップ（4視点のP0/P1/P2を統合）

### P0（コンテンツ増量前の"詰まり"解消 — ✅ 完了）
- ✅ バトルのカテゴリタブ / ✅ briefingサブタブ
- ✅ **アーキタイプグルーピング**: 編成ロスターをアーキタイプ別セクション表示（機密特化/完全DoT/可用DoS/装置破壊/横展開/バフ支援）。撃破/カードは編成上限3のため戦闘側は非対象。
- ✅ **図鑑のスケール対応**: マルウェア図鑑を新設し、マルウェア/カードのタブ＋ゲージ(🔵🟢🟡)/所持フィルタ＋サムネイルグリッドに刷新（50+件でも絞り込める）。

- ✅ **CIコンテンツlint**（`test/sim.mjs` シナリオ23）: 実CVE/IP/URL/実行可能コマンドを含む記述でビルドを落とす＋全ユニット/カードに対策(defense)必須。ストア/B2Bのブロッカー解消。

### P1（リテンションの深み）
- **`g.status` バッグ ＋ `endTurn` 減衰フック**（新メカニクスの共通基盤）。これを土台に:

- **数式ガードレール**（バトルレビュー）: 隠密の二値崖→漸減化、多ゲージ技の警戒度過少課金(R2)是正、`evade`の一時無効化(R4)、`detectMul`クランプ。
- **母港ハブ＋下部タブバー**（母港/図鑑/開発/出撃）。進化を"開発"へ移設。
- **スコア＋星評価＋高難度モード**（`blue:{alert,react}`でBeeline/Meander人格）＝調査裏付けのリテンション面。
- **デイリー目標＋アカウント級メタツリー**（devPの新しい使い道）。
- **リテンション計測**（localStorageでD1/D7/ステージ到達率）＝調査が指す長期効果の未知を計測。
- **コンテンツパック構造**（ステージ/世代をデータフラグでゲート）＝非略奪的な課金の器。

## 付録: レビュー要旨（4エージェント）

- **ゲームデザイン**: docsに仕様済みの未実装コンテンツを取り込めば低リスクで増量可。世代バケットを埋め、進行/リテンション（デイリー/メタ/イベント/スコア）を追加。ガチャは非推奨。
- **UI/UX**: `.screen`+`show()`とid接頭辞付き`listActions`は良い骨格。3つの継ぎ目（行動グリッド/briefing/フラットnav）をメニュー化。iOS `dvh`/safe-area、`.path`横スクロール。
- **バトルシステム**: 3チョークポイントは拡張に耐える。差別化軸が`ignoreH`1つのみ→`g.status`基盤＋8アーキタイプ＋コンボで"深さ"を。隠密崖/多ゲージ警戒度/evade永続/detectMul無限などのガードレール。
- **商用化**: 強いバーティカルスライス。無料Web＋パック＋B2B教材の二層。倫理ガードレールは資産。次イテはオンボーディング/図鑑/育成体感/CIゲートに投資し、リテンションを計測。
