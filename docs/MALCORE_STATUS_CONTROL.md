# マルこれ — 可変ステータスと監査・診断カットイン 🎯🛡️

> フェーズ0-A の設計。サーバユニットに HP(CIA) とは別の **可変ステータス2種** を持たせる。
> **ハードニング（防御力）** と **脆弱性（被弾率）**。
> ブルーチーム（敵）の **システム監査／セキュリティ診断** が自分に有利な方向へこれを動かし、
> レッドチーム（プレイヤー）は **特定条件のカットイン** で監査・診断を逆用し、敵ステータスを有利に操る。
> ＝ HPを削る前に「**ステータスの綱引き**」が走る、艦これのカットイン的な駆け引き。

- 関連: `MALCORE_DEFENSE_MODEL.md`（緩和の中身）／`MALCORE_ATTACK_MODEL.md`（多段・偵察）
- この2ステータスは、既存ダメージ式の **2つのツマミ** として全設計を束ねる。

---

## 1. サーバユニットの3レイヤー・ステータス

| レイヤー | ステータス | 役割 | 増減するか |
|---|---|---|---|
| 体力 | **HP = CIA（🔵🟢🟡）** | 削り切れば勝利 | 攻撃で減る（戻りにくい） |
| 防御 | 🛡️ **ハードニング（防御力）** | 受けるダメージの **緩和倍率** | **動的**（監査↑／攻撃側カットイン↓） |
| 露出 | 🎯 **脆弱性（被弾率）** | 攻撃の **命中・会心** | **動的**（診断↓／攻撃側カットイン↑） |

> HP は“結果”、ハードニングと脆弱性は“通りやすさ”。後者2つを先に有利化してから殴るのが上手いプレイ。

---

## 2. ダメージ式への組み込み（2つのツマミ）

`MALCORE_DEFENSE_MODEL.md` の式に、可変ステータスを掛ける：

```
有効ダメージ = 基礎攻撃力(C/I/A)
             × (1 − 緩和率 × 防御力倍率)      ← 🛡️ ハードニング
             × 命中補正                       ← 🎯 脆弱性

  防御力倍率 = 0.5 + ハードニング/100      （H=0→0.5倍, 50→1.0倍, 100→1.5倍）
  命中補正   = 0.6 + 脆弱性/100 × 0.8       （V=0→0.6, 50→1.0, 100→1.4）
  ・(緩和率 × 防御力倍率) は上限0.8（最低20%は必ず通る）
  ・脆弱性が高いほど会心（追加ダメージ）も出やすい
```

- **ハードニングが高い敵** → 緩和が強化され、噛み合う攻撃でもダメージが伸びない。
- **脆弱性が高い敵** → どの攻撃も当たりやすく会心も増える。
- → 「**ハードニングを下げ、脆弱性を上げてから本命を撃つ**」が黄金パターン（数値はA-3で確定）。

## 3. ブルーチーム（敵）の監査・診断 — 不利を押し返す力

敵は放っておくと **自己強化** する。これが「長引かせると敵が硬くなる」時間的プレッシャーになる。

| 行動 | 効果 | 発動トリガー | 現実の対応 |
|---|---|---|---|
| **システム監査** | 🛡️ ハードニング **+15**（設定不備是正・ポリシー適用） | 一定ターン経過／警戒度が閾値超え | 構成監査・是正、ポリシー強制 |
| **セキュリティ診断** | 🎯 脆弱性 **−15**（弱点にパッチ・攻撃面縮小） | ボスフェーズ移行／被害検知後 | 脆弱性診断＋是正、攻撃面管理 |

- **騒がしく攻める（警戒度↑）と監査が誘発** → 敵が硬くなる。静かに進める動機になる。
- 監査・診断は **演出カットイン**（敵側）として表示。「ブルーチーム出動！」で盤面が引き締まる緊張感。
- 🎓 学び: **継続的な監査・診断は攻撃の窓を狭める**。守りは“一度きり”でなく回し続けるほど効く、という体感。

## 4. レッドチーム（あなた）の監査・診断カットイン — 逆用して有利化

プレイヤーは **特定条件** を満たすと **カットイン**が発動し、攻撃者側の偵察・診断で敵ステータスを有利方向へ操作する。
（攻撃者の偵察・弱点発見は、いわば“裏返しの監査・診断”）

| カットイン | 効果 | 主な発動条件（例） |
|---|---|---|
| 🔍 **侵入前偵察カットイン** | 🛡️ ハードニング **−20**（防御の穴を特定・無効化） | 偵察ロール2体以上を編成 ＋ 情報レベル ≥ 閾値 |
| 🧪 **脆弱性診断カットイン** | 🎯 脆弱性 **+25**（悪用可能な弱点を露出させる） | 対象に刺さる脆弱性カードを所持 ＋ 技術レベル条件 |
| ⚙️ **設定不備曝露カットイン** | 🛡️ −15 ＆ 🎯 +15（両取り・小） | 同一世代のマルウェアで編成を揃える（同型ボーナス） |
| 🔗 **連鎖カットイン** | 効果量UP＋持続延長 | 偵察成功を連続（コンボ）で達成 |

- カットインは **数ターン持続**（または当該戦闘中持続）。発動時は専用の演出ログ（擬似・非実行）で“決まった”感を出す。
- これが **編成（ロール）と資源運用** に意味を与える：偵察型を入れる／情報レベルを貯める／同世代で揃える、が報われる。
- 🎓 学び: 攻撃者の **偵察・診断こそが攻略の半分**。＝防御側は「自分の脆弱性を診断され尽くす前に塞ぐ」「露出（脆弱性）を下げ、ハードニングを上げる」ことの重要性が裏から分かる。

## 5. ステータス綱引きの流れ（1戦闘の典型）

```
   開戦
    │  ブルー監査でHが高め・Vが低め（硬い・当てにくい）
    ▼
 ① 偵察を稼ぐ ──▶ 🔍偵察カットイン発動：ハードニング −20
    │
 ② 脆弱性カード提示 ─▶ 🧪診断カットイン発動：脆弱性 +25
    │           （ここで“通りやすさ”が一気に有利化）
    ▼
 ③ 本命の撃破ロールで CIA を一気に削る（緩和小・命中高・会心）
    │
    ✗ もたつくと… ブルーが システム監査/診断 で押し返す（H↑ V↓）
    ▼
   速さ vs 確実さ の駆け引き
```

> ハードニング・脆弱性は **0〜100でせめぎ合う**。攻撃側カットインで傾け、ブルー監査で戻される“シーソー”が戦闘のリズムになる。

## 6. 世代・難度との連動
- 上位の敵（N省など）は **監査・診断の頻度と回復量が高い**＝放置すると一気に硬化。短期決戦を強いる。
- ブルーの監査・診断が **シグネチャ世代→AI異常検知世代**に上がると、レッドのカットイン条件も厳しくなる（古い偵察手法が通らない）→ プレイヤーの世代進化を促す。
- これにより `MALCORE_DEFENSE_MODEL.md` の「防御の世代進化」と一体で噛み合う。
