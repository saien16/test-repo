# マルこれ 調査レポート — サイバーセキュリティ学習ゲームの「面白さ・遊びやすさ・需要」

> 目的: 攻撃側・防御側のセキュリティ教育ゲームを「面白さ（ゲーム性・エンゲージメント）」「遊びやすさ（UX・学習曲線）」「需要（市場・ターゲット層・成功要因）」の3軸で調査し、**マルウェアを操作してCIA三要素を攻略するKanColle風コレクション育成ゲーム**の設計判断に活かす。
>
> 調査手法: deep-research ワークフロー。6角度 → 25ソース取得 → 33主張抽出 → 3票制の敵対的検証（2/3で棄却）→ **20確認 / 5反証**。以下は確認済み主張のみを掲載（信頼度: ★★★=3-0全会一致 / ★★=2-1）。

---

## 1. 需要（市場・ターゲット層・成功要因）

- **ゲーム/ゲーミフィケーション×セキュリティ教育は活発で確立した領域** ★★★
  2018–2024でIEEE/ACM/Springerに230本の一次研究。2014–2024で53本（PRISMA準拠）。2007–2022で80のゲーミフィケーション事例（74論文）。ジャンルとして需要が実証されている。〔arXiv 2406.17882 / 2403.10118 / ScienceDirect S0167404824006138〕
- **既存タイトルの主対象は「専門職・大学生・前提知識のある層」に偏在** ★★★。一般消費者/カジュアル層向けは少数派 ★★★ →**未充足市場**。〔ScienceDirect S0167404824006138〕
- **既存ゲームは技術トピック（ハッキング・NW）偏重で人間・行動面が手薄** ★★（2-1）→ 設計空間の空白。〔同上〕
- **従来型トレーニング（フィッシング訓練・動画・テスト）は時間とともに効果減衰** ★★★ → 新奇で没入的な形式そのものへの需要。〔arXiv 2304.01142〕

## 2. 面白さ（ゲーム性・エンゲージメント）

- **抽象的・技術的な題材こそゲーミフィケーションの効果が最大化** ★★★。CIA三要素のような抽象概念は、まさにゲーム化が狙うべき痛点。〔arXiv 2406.17882〕
- **競争的スコアリングは実測でエンゲージメントを生む** ★★★（CyberMoraba: 攻撃側/防御側が配置精度で「意識スコア」を競う。40名で「面白い＆学べた」を実証）。〔arXiv 2403.10118〕
- **差別化された敵AIアーキタイプが戦略性と学習を駆動** ★★★。IDG研究では高速直進「Beeline」／低速徘徊「Meander」の2敵型で、プレイヤー行動が反応的→先読み的へ変化。**攻めのテンポが違う敵**が習熟の快感を生む。〔arXiv 2305.03062〕
- **攻撃者視点＝独自ジャンル「アタックシミュレータ」として成立** ★★（2-1）。防御視点の従来SGと差別化される新カテゴリ。〔arXiv 2304.01142〕
- **行動と学習フィードバックの結合**が中核教育メカニズム ★★★ — 各攻撃で「攻撃者の意図」と「成功時の帰結」を提示。〔arXiv 2304.01142〕

## 3. 遊びやすさ（UX・学習曲線・対象）

- **対象は非専門家/一般ユーザーを想定でき市場は広い** ★★★。〔arXiv 2304.01142〕
- **防御ループのお手本**: IDGは「アラート監視→analyze / remove / restore を選ぶ」明快な3択。CIA防御を遊びに落とす際の参照モデル。〔arXiv 2305.03062〕
- **予測可能で読みやすい強敵は"マスタリーの弧"を生む** ★★★（Beelineは当初手強いが攻撃パターンが legible なので攻略法を学べる）→ 難敵は理不尽でなく「読める難しさ」に。〔arXiv 2305.03062〕

## 4. 効果の限界（正直な留保）

- **短期効果は確認、長期効果は未実証** ★★★。〔Serious Games Society 719〕
- **個々のゲーム要素の単体評価が不足／非IT層向けカスタム戦略も未整備** ★★★。〔同上 / ScienceDirect〕

## 5. ⚠️ 敵対的検証で反証された主張（3票中3票で棄却＝設計根拠にしない）

1. ❌ **「CTF（Jeopardy型）がこの領域の支配的・実証済み成功パターン」** — 出典はCTFを列挙しただけで「支配的/実証済み」とは述べていない。**コレクション×物語型を捨ててCTFに寄せる理由にはならない。**〔arXiv 2406.17882〕
2. ❌ **「ストーリーテリング＋チームリーダーボード＋対話シナリオが効果を生んだ具体要素」** — 個別要素の効果は分離評価されておらず断定不可。〔Serious Games Society 719〕
3. ❌ **「換字暗号/ハッシュ/SQLi等が検証済みトピック分類として使える」** — 出典は成功要因として validate していない。〔arXiv 2406.17882〕
4. ❌ **「CTFの線形シーケンス＋文脈埋め込みが実証済み学習曲線設計」** — 実証の裏づけなし。〔arXiv 2406.17882〕
5. ❌ **「多くの成功ゲームは明示的な教育フレームワークに基づく＝確立した成功慣行」** — レビューはそう結論づけていない。〔ScienceDirect S0167404824006138〕

## 6. マルこれへの設計示唆

| 調査知見 | マルこれでの反映 / 強化案 |
|---|---|
| 抽象概念こそゲーム化が効く★★★ | ✅ CIA三要素をHPゲージ化済み。撃破時に「機密性喪失＝情報漏洩」等の**帰結の一言解説**を足すと教育価値↑（#2の行動↔学習結合） |
| 差別化した敵テンポ★★★ | 🔧 ブルーチームに **Beeline型（高速直進=react高）/ Meander型（低速徘徊=alert高）** の性格差を明示。現行 `blue:{alert,react}` で表現可能 |
| 読める強敵→習熟の弧★★★ | 🔧 X省/最終ボスの警戒度上昇を**予測可能パターン**として提示（次ターン予告等）。理不尽でなく「読める難所」に |
| 攻撃者視点は独自ジャンル★★ | ✅ マルウェア操作＝アタックシミュレータ路線は研究的にも新規性あり。教育的擬似コード演出の方針を維持 |
| 一般層が未充足市場★★★ | 🔧 チュートリアル/学習曲線をカジュアル層向けに。前提知識ゼロで入れる導線を |
| 防御ループの明快3択★★★ | 💡 将来「防御側モード」なら analyze/remove/restore 型3択が参照モデル |
| 長期効果は未実証★★★ | 💡 反復プレイ動機（コレクション/育成）は**リテンション実験の価値**がある領域＝マルこれの強みが刺さる |

**総括**: 「マルウェアを操作してCIAを攻略する攻撃者視点のコレクション育成」は、文献に照らして (a) 新規ジャンル性、(b) 抽象概念のゲーム化適性、(c) 一般層という未充足市場、の3点で追い風。一方で **CTFが唯一の正解という通説は今回のデータでは支持されず**、コレクション×物語型を貫く判断は妥当。最大の未知数は「長期学習効果」で、育成ループの反復動機で差別化できる余地がある。

## Caveats（この調査の限界）

- ソース25件中、一次学術ソースは9件。残りは quality=unreliable のブログ/市場レポ/wiki。
- 市場規模の**定量数値**（Mordor / ResearchAndMarkets 等）は検証を通過せず（claimCount 0）＝本レポートに確度ある市場規模データは無し。
- KanColleのガチャ/擬人化メカニクスの角度は検証済み主張ゼロ。
- 日本語ソースはヒットせず、英語圏の学術知見が中心。
- 合成段が不具合でstubを返したため、確認済み主張は検証ログとjournalキャッシュから復元して再構成した。
