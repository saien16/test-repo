はじめての方へ

コードの「危ないところ」を
見つけてくれる道具

GRIMOIRE（グリモワール）は、セキュリティに詳しくなくても使える脆弱性スキャナーです。3分で全体像がつかめます。

あなたのコードを読んで、
危ないところを見つけ、
直す順番まで教えてくれます。

こんな不安、ありませんか

🤔

「自分のコードにセキュリティの穴があるか、そもそも分からない」

😵

「診断ツールを入れても、警告が何百件も出てどれから手をつければいいのか」

😨

「一つひとつは小さな問題でも、繋がると大事故になるのが怖い」

GRIMOIRE はこの3つに答えます。

使い方は3ステップ

ターミナルにコマンドを打つだけ

1じゅんび

準備する

Node.js と、AIを使うためのAPIキーを用意します。最初の一回だけです。

$ npm install && npm run build
2じっこう

スキャンする

調べたいフォルダを指定して実行します。あとは待つだけ。AIがコードを読んでいきます。

grimoire ./my-app
3よむ

結果を読む

読みやすいレポートが出ます。ブラウザで見るなら HTML で出力してください。

grimoire ./my-app -f html -o report.html

結果は、ここだけ見れば大丈夫

最初は3つだけ覚えれば十分です

緊急 高 中
色 = 深刻さ。 赤（緊急）や橙（高）から順に見ます。数字（CVSS 0〜10）が大きいほど危険です。
92
「優先対応アクション」を上から。 順番はAIの気分ではなく機械が計算しています。1番から直すのが、いちばん効率のいい減らし方です。
✂
チョークポイント＝急所。 このマークがある箇所は、1つ直すだけで複数の攻撃経路を断てます。いちばん得な直し方です。
いちばん大事なこと

検出0件だから安全
検出0件は「まだ調べきれていない」かもしれない

だから GRIMOIRE は、スキャンが最後まで走ったかを別に伝えます。「0件」で安心する前に、そこを確かめてください。「見つからなかった」は「無い」の証明ではありません。

レポートの冒頭には いつ・どこを・何ファイル／何行 見たかが出ます。設定を間違えて数ファイルしか見ていなければ、そこに出ます。まずここを見て、思っていた範囲と合っているか確かめてください。
